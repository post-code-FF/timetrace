# TimeTrace в GNOME 51

В версии 0.1.5 исправлены отслеживание активного окна, простой, блокировка
и восстановление после перезапуска GNOME Shell. Расширение передаёт события
через D-Bus; приложение восстанавливает пропущенные события из ограниченной
истории. При недоступном расширении учёт активного окна приостанавливается.

Имя команды и приложения — `timetrace` / TimeTrace. Существующие настройки
в `~/.config/timetrace` и история в `~/.local/share/timetrace` продолжают
использоваться. Копировать базу при обновлении не нужно.

При запуске в GNOME 51 на Wayland TimeTrace автоматически устанавливает или
обновляет своё расширение в пользовательском каталоге и пытается его включить.
Права администратора, скачивание расширения и команды в терминале не нужны.
Неизменённые файлы при повторных запусках не переписываются.

Если GNOME ещё не обнаружил расширение или нужно загрузить обновлённый код,
внизу окна TimeTrace появится просьба выйти из сеанса и войти снова.
На других версиях GNOME несовместимое расширение автоматически не устанавливается.

При необходимости ручная установка из исходников также доступна:

```bash
bash scripts/install-extension.sh
```

После обновления выйдите из сеанса GNOME и войдите снова, затем выполните:

```bash
gnome-extensions enable timetrace@timetrace.app
gnome-extensions info timetrace@timetrace.app
```

Ожидается состояние ACTIVE. UUID остался прежним: обновление заменяет старый протокол.
Новая версия расширения заявляет поддержку GNOME 51.

Диагностика: `TIMETRACE_DEBUG=1 timetrace`. Заголовки окон в диагностический
лог GNOME-бэкенда не записываются. Для проверки протокола без рабочего сеанса:

```bash
gjs -m tests/extension-harness.js src/timetrace/assets/gnome_extension/extension.js
TIMETRACE_PRIVATE_BUS_TEST=1 dbus-run-session -- python scripts/test-dbus-integration.py
```

Эти проверки используют имитацию Shell API и отдельную шину D-Bus;
они не заменяют проверку в настоящем сеансе GNOME.
